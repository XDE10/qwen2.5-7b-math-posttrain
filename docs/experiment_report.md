# 技术与实验复盘报告

本文系统总结 `Qwen2.5-7B-Instruct` 在单卡 RTX PRO 6000（96 GB，Colab G4）条件下的数学推理后训练全链路：去污数据构建、全参 QFFT 复现、双教师对照、单卡 LoRA-GRPO / MMR-DR-GRPO 探索，以及 RL 阶段未达显著增益的代码级与遥测级根因诊断。

---

## 1. 数据构建与去污

- **1,000 题监督集**：以 `simplescaling/s1K-1.1` 为基础，对 5 个正式评测集执行规范化 13-gram + 序列相似度（≥0.6）去污与逐对人工复核（见 [`configs/decontam_review.json`](../configs/decontam_review.json)），发现并替换了与 MATH-500 `test/intermediate_algebra/1063.json` 同题的 `s1k11/row/0918`。
- **双教师轨迹与偏离说明**：
  - R1 轨迹取自 s1K-1.1，平均 9,636 token、最大 26,835 token，可核对 750 题正确率 64.3%。
  - DeepSeek-V4.1-Flash 轨迹由 API 补齐，平均 10,017 token、最大 32,496 token，可核对 750 题正确率 67.3%；清洗了思考段中 552 处隐藏参数元叙述。
  - **预注册偏离透明记录**：19 道 Flash 轨迹始终超出 32K 窗口的题目未做成对剔除，改为以获批 OpenR1 原题替换，选题时参考了 Flash 轨迹长度与少数对错条件；其余 981 题严格遵循“按时间顺序取首条完整且 ≤32K 的尝试，不按对错过滤”。
- **RL 题池**：早期 DAPO-GRPO 试点采用 1,551 道去重去污题（918 道中等题 + 633 道 E0 难题）；MMR-DR-GRPO 阶段采用去污后的 `Elliott/Openr1-Math-46k-8192` 顺序冻结子集（400 / 1,200 / 4,000 题）。

## 2. 全参 QFFT 复现与双教师对照

### 2.1 核心正向结果（`R1 QFFT-750`）
在单卡 G4 上通过 **DeepSpeed ZeRO-2 CPU Offload + 梯度检查点 + Liger FusedLinearCrossEntropy** 实现 7B 全参训练（response-only、无 chat 标记、无 EOS，16K 窗口、有效 batch 8、LR `1e-5`、cosine 6 epochs、750 步）：
- **竞赛 100 题**：`26.06% → 33.63%`（**`+7.56 pp`，95% CI `[+3.88, +11.44]`**，统计显著）；
- **MATH-500**：`76.80% → 80.50%`（`+3.70 pp`）；
- **自适应长度特征**：相比公开标准 SFT 锚点 `sft_repro`（GSM8K `2,191` tok、MATH-500 `6,837` tok、AIME24 `22,040` tok），自训 `R1 QFFT-750` 在简单题上保持短推理（GSM8K `476` tok、MATH-500 `3,115` tok），难题上自动触发长思考（AIME24 `14,651` tok），与官方 `QFFT-S1-7B` 长度分布几乎重合。

### 2.2 与 QFFT 原论文数字的同口径核对
直接对比论文（arXiv:2506.12860 Table 2 & 6）纸面数字与本项目同口径重测官方权重 `lwl-uestc/QFFT-S1-7B`：

| 评测集 | QFFT 论文原表 | 作者权重（v93 同口径实测） | 自训 `R1 QFFT-750` |
|---|---:|---:|---:|
| GSM8K | 91.0% | 92.27% | 91.43% |
| MATH-500 | 80.2% | 81.10% | 80.50% |
| AMC23 | 55.3% | 61.25% | 59.06% |
| AIME24 | 20.6% | 20.83% | 18.54% |
| AIME25 | 17.2% | 16.04% | 14.79% |

- 论文采用 `top_p=1.0`、`max_tokens=32000` 与旧版 `latex2sympy2` 规则脚本；本项目采用 `top_p=0.95`、`max_model_len=32768` 与 `Math-Verify 0.9.0`，故同一官方权重在本管线下 AMC23/GSM8K/MATH-500 均略高于论文原表。
- 在严格同口径下，自训 `R1 QFFT-750` 与作者官方权重竞赛 100 题仅差 `−1.94 pp`（95% CI `[−4.06, +0.06]`，跨零），成功复现论文效果。

### 2.3 `Flash QFFT` 负结果诊断
同样采用 QFFT 格式（无 EOS）在 DeepSeek-V4.1-Flash 32K/b16 上训练 378 步，竞赛 100 题反降至 `19.31%`，MATH-500 降至 `67.00%`。主要观测是严重失控生成与截断（AIME24 截断 **44.6%**、AIME25 **41.9%**，对比 R1 仅 10.4% / 2.5%）。由于该对照同时改变了教师轨迹、训练窗口（32K vs 16K）和有效 batch（16 vs 8），严格归因需补齐同窗口/同 batch 对照。

## 3. RL（LoRA-GRPO / MMR-DR-GRPO）探索与深度失败归因

在 `R1 QFFT-750` 起点上先后推进了三条 RL 路线：

1. **DAPO LoRA-GRPO（16K, LR `1e-5`, β=0）**：
   - 修复了 R1 缺最终段标签导致 `no_answer` 高达 88.3% 的奖励漏判（引入完整末框回退后降至 23.4%，零方差组从 50% 降至 18.8%）。
   - 验证了生成上限对信号密度的影响：8K → 12K → 16K 截断率从 `35.9%` 降至 `7.0%`。
   - **IS 掩码诊断与 59 题留出实验**：离线诊断发现 `sequence_mask` 会把部分正确长回答的 IS 权重压到 `<1.5e-18`；改用 `token_mask` 后在 2026 独立竞赛 59 题上精度持平（`+0.21 pp`），但**平均输出显著缩短 16.8%（−1,743.5 token）**。
   - 累计 30 步竞赛 100 题 `32.13%`（`−1.50 pp`），主要掉分在 AMC23（`−4.69 pp`）；前 30 步中 E0 难题吃掉 64.3% token 且 49/113 组全零奖励。

2. **MMR-DR-GRPO（旧 50 步 & 新版排除截断 1→312 步）**：
   - **旧 50 步**（400 题，完整 5 项评测）：竞赛 `34.50%`（相对 QFFT `+0.88 pp`，CI `[−1.38, +3.31]`），GSM8K `92.42%`（`+0.99 pp`，p=0.062），AIME24/25 的 `maj@16` 分别从 `33.3%→40.0%`、`20.0%→30.0%`。它是所有 RL 尝试中五项最均衡、无明显退化的检查点，但统计上仍未证明显著提升。
   - **新版 1→312 步**（1,200→4,000 题，排除截断样本参与 MMR 均值）：DEV249 在 step 250 出现局部高点 `84.54%`（`+2.61 pp`, p=0.057），但 step 300 回落到 `81.93%`；正式评测中 step 80/100 竞赛综合均略低于基线（`32.38%` / `33.38%`），step 250 在已完成的 4/5 项正式评测中 AMC23 回落至 `56.25%`（`−2.81 pp`），证伪了 DEV249 的单点波动。

3. **为什么 311 步 MMR-DR-GRPO 始终推不动？（四大核心根因）**
   - **根因 1 — 策略几乎被焊死在起点**：统计 step 1–311 全部遥测日志，**KL 散度全程钉在 `0.0022 ~ 0.0031`**，**entropy 横盘在 `0.203 ~ 0.217`**，训练准确率 `correct_frac` 停留在 `48% ~ 53%`。代码层面，作者原配方 `max_completion_length=3584`，本项目扩到 **`16,384`（4.57×）**，而 `dr_grpo` 损失以固定常数 `max_completion_length` 为分母归一化，导致有效梯度被额外稀释 **2.5–4.5 倍**；再叠加 LoRA 下极小的 `LR 1e-6`（500 步 cosine 衰减至 `4.4e-7`）与强 KL 拉力 `beta=0.04`，参数几乎未走出起点邻域。
   - **根因 2 — 复合奖励反向污染正确性优势**：对 step 243–250 与 293–300（16 步、768 条真实 rollout）的离线精确重放表明，MMR 相似度惩罚 + 余弦长度奖 + 格式奖叠加后：
     - **全对组（all_correct）中 145/181 条正确回答拿到负优势**；
     - **全错组（all_wrong）中 20/60 条错误回答拿到正优势**；
     - **混合组（mixed）中仍有 31 条正确回答被压成负优势**；
     - 本应零梯度的同质组消耗了总 `|advantage| × tokens` 更新量的 **18.35%**。
   - **根因 3 — 格式与模板错位**：MMR 沿用上游 DeepSeek 风格 `<think>...</think><answer>...</answer>` 系统提示与 `'\n</think>\n'` 格式奖，而 QFFT-750 以 `<|im_start|>answer` 训练、正式评测又切回 Qwen 默认提示模板。
   - **根因 4 — 单卡小 batch 与高基线约束**：单张 G4 每步 8 题 × 6 抽耗时 ~17 分钟，每步仅约 4.6 个有效混合信号组；叠加新追加 2,800 题未完成逐题人工金标审校、以及 QFFT-750 本身已在竞赛集拉升 `+7.56 pp`，单卡短步预算远小于公开论文多机多卡规模（如 Laser-D 32 卡 600–900 步 × 128 题/步）。

## 4. 局限性与后续改进方向

1. 若具备多卡算力，改进 RL 应优先采用：**纯 0/1 最终答案奖励（移除 MMR 相似度惩罚与冲突格式奖）+ 按有效 token 归一化（DAPO）而非 16K 固定分母 + 适配 LoRA 的学习率（`5e-6 ~ 1e-5`）与更低 KL（`beta ≤ 0.01`）+ 提前按 QFFT-750 实测通过率筛出 1–5/6 中等难度高质量题池**。
2. 当前实验为单随机种子，按题配对 bootstrap 量化了评测采样与题目方差，未覆盖多训练种子方差。
3. 评测聚焦数学推理，未覆盖通用指令遵循（如 IFEval）遗忘测试。
